# 官方战斗特效素材部署指南（通俗版）

## 这是什么东西？

游戏里干员攻击、放技能、挨打时那些炫酷的特效动画，用的是《明日方舟》官方素材。
因为这些素材有版权，不能放进公开的代码仓库（GitHub），所以要把它们单独打成一个压缩包，手动上传到你的游戏服务器。

> 没有这个素材包，游戏**照样能玩**，只是特效会变成简单的“程序化”效果（没那么华丽）。属于锦上添花，不影响任何功能。

## 你需要准备什么？

一个压缩包，文件名叫下面任一个：

- `local-fx-bundle.tar.gz`（推荐）
- `local-fx-bundle.zip`

里面装的是游戏的官方战斗特效文件。

## 第一步：如果你还没有这个压缩包（在自己电脑上做）

1. 找到游戏项目文件夹（根目录，里面有 `public`、`data`、`server` 等文件夹）。
2. 打开终端 / 命令行，进入这个根目录。
3. 执行下面任意一条命令来打包：

   ```bash
   # 方式 A：打成 .tar.gz（推荐，Linux / 容器通用）
   tar -czf local-fx-bundle.tar.gz -C . public/assets/local/fx data/local-fx.json

   # 方式 B：打成 .zip（Windows 上也方便）
   zip -r local-fx-bundle.zip public/assets/local/fx data/local-fx.json
   ```

   执行完，根目录里就会出现 `local-fx-bundle.tar.gz`（或 `.zip`）。

   ⚠️ 一定要在**项目根目录**下执行，压缩包里才会带上正确的 `public/assets/local/fx/...` 和 `data/local-fx.json` 结构。

## 第二步：上传到服务器

把压缩包传到你游戏服务器上的**项目根目录**，也就是 `Stronghold-Protocol/` 这个文件夹（里面已经有 `public/`、`data/`、`server/`）。
- 如果用容器 / 面板，路径通常是 `/home/container/Stronghold-Protocol/`。

## 第三步：手动解压

在服务器的项目根目录下执行：

```bash
# 如果是 .tar.gz
tar -xzf local-fx-bundle.tar.gz

# 如果是 .zip
unzip -o local-fx-bundle.zip
```

解压后，文件会自动落到：

- `Stronghold-Protocol/public/assets/local/fx/...`（特效贴图与描述）
- `Stronghold-Protocol/data/local-fx.json`（特效清单）

## 第四步：重启服务器

解压完成后，重启游戏服务端（或重启容器 / 面板），让服务器加载新素材。

## 第五步：验证

进游戏，选个干员放技能，看有没有华丽的官方特效。
如果还是简单特效，检查：

1. 压缩包是不是上传到了**项目根目录**（不是某个子文件夹里）。
2. 解压后 `public/assets/local/fx/` 里是否有文件（正常应有上万份）。
3. 重启服务器后再试一次。

## 常见问题

- **没有这个压缩包会怎样？** 游戏照常玩，只是特效简化版，不影响功能。
- **压缩包要放进代码仓库吗？** 不要。它因版权被 `.gitignore` 排除，且体积大；每次部署服务器单独上传即可。
- **换了服务器怎么办？** 把同一个压缩包再上传、解压一次就行，步骤不变。
